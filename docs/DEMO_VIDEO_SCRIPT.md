# LASSO final demo script — target 2:45

Use a real native WebMCP agent. Keep the product full-screen, the agent panel visible only when it is performing a call, and use generated voice-over/captions rather than a talking head.

## 0:00–0:12 — Hook

**Visual:** Full map, six late deliveries.

**Voice-over:**

> Giving an AI a task is easy. Showing it exactly what part of a live system it may understand and change is not.

**On-screen text:** `DRAW WHAT YOUR AGENT CAN TOUCH`

## 0:12–0:32 — Gesture becomes contract

**Visual:** Draw the lasso around six deliveries, Aino, and Leo. Open Technical proof as the schema enums appear.

**Voice-over:**

> In LASSO, I do not enumerate IDs in a prompt. I draw the boundary. The page compiles that transient gesture into a typed WebMCP contract containing only the selected resources.

**On-screen text:** `HUMAN UI → TYPED AGENT API`

## 0:32–0:58 — The agent authors and fails

**User prompt:**

> Recover as many late deliveries as possible without overtime. Stay within my scope, author the assignments yourself, and request more scope only if necessary.

**Visual:** Agent inspects and submits the first plan. Show structured rejection.

**Voice-over:**

> The agent authors the plan. LASSO does not optimize for it. This proposal fails: D15 needs refrigerated capacity, and Aino would exceed protected capacity and overtime.

## 0:58–1:24 — Scope negotiation

**Visual:** Agent calls the opaque expansion request. Mika glows amber. Human presses Include resource. Show R2 invalidated and R3 adding `MIKA-03` to the driver enum.

**Voice-over:**

> The validator exposes an opaque opportunity outside the contract. The agent can ask for it, but cannot grant itself authority. My click creates a new tool revision, and only now does Mika's resource ID enter the WebMCP schema.

**On-screen text:** `THE AGENT MAY ASK. THE HUMAN CHANGES THE CONTRACT.`

## 1:24–1:49 — Verified plan

**Visual:** Agent submits repaired assignments; dashed proposed routes appear. Show 6→1, three routes, +4.0 km, zero overtime.

**Voice-over:**

> The repaired plan recovers five deliveries with three route changes and no overtime. D18 remains late because its recovery window is already closed.

## 1:49–2:13 — Exact authority and execution

**Visual:** No apply tool. Human authorizes. Contract diff adds exact `apply_plan`, one plan ID, one epoch. Agent invokes it. Routes become solid.

**Voice-over:**

> There is still no write capability. I authorize this exact verified plan once. A consequential apply tool appears, bound to the current plan and live state. The agent executes it, and the capability disappears.

## 2:13–2:28 — Prove the boundary

**Visual:** Show Mika still has D06 plus D15, unselected routes unchanged, then attempt stale replay and show rejection.

**Voice-over:**

> Outside commitments remain untouched, every delivery has one owner, and the consumed capability cannot be replayed.

## 2:28–2:45 — Close

**Visual:** Applied map, contract trace, simple pipeline graphic.

**Voice-over:**

> LASSO turns direct manipulation into a programming language for a visiting agent. The map is the prompt. The boundary is the permission.

**End card:**

`LASSO`

`Human gesture → ScopeCompiler → ephemeral WebMCP API`
